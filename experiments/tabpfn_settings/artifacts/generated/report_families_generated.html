能不能从「训练配置」预测最终效果？

我们想知道：如果只告诉你一套神经网络训练配置（用什么模型、什么优化器、训练多久……）， 还没真正看最终测试分数，一台「表格预测模型」能不能猜出这套配置训完后大概有多好。 本报告假设你没听过 TabPFN，从它是什么讲起，再讲我们怎么造数据、怎么评估。

1. TabPFN 是什么？（零基础）

TabPFN（Tabular Prior-Data Fitted Network）是 Prior Labs 提出的一种专门吃「表格数据」的预训练模型。 你可以把它想成：别人已经在海量「随机生成的小表格任务」上预先训练好了一个大网络； 轮到你时，你不必从零训练一棵随机森林或一个神经网络，只要把已有的若干行（特征 + 答案）和新行的特征一起喂给它，它就能给出新行的预测。

你熟悉的普通机器学习

  • 拿到一张表，用梯度下降 / 建树等算法从头拟合这张表
  • 参数会根据你的数据被改写；数据一换通常要重训
  • 例子：Ridge、随机森林、XGBoost、自己训一个 MLP

TabPFN 的用法（本实验）

  • 模型权重事先训好、基本不动
  • fit(训练行) ≈ 「请记住这些例子」——更像把例子放进上下文，而不是长期改权重
  • predict(新行) ≈ 根据刚看到的例子，对新行给出数值预测
  • 特别适合行数很少（几十到上千）的表格回归/分类

三个容易误会的点

  1. 「训练样本量」指什么？ 下文写的 n_train≈30，是我们给 TabPFN 看的「已标注配置」条数。 不是 TabPFN 自己当初预训练用了多少数据，也不是下面 ArchitectureIQ 里那个神经网络训了多少样本。
  2. 它预测的不是图片/文本，而是表格里的数字。 每一行是一组特征；我们要它预测一列连续数值（比如测试误差）。
  3. 我们用的是开源 TabPFN，在本地 GPU 上跑（A100），不是调用云端黑盒 API。 版本是回归器 v2.5 的默认 checkpoint。

官方概念可参考：PriorLabs/TabPFN。 本实验只把它当成「表格上的强基线回归器」，与 Ridge、梯度提升树对比。

2. 我们在问什么问题

ArchitectureIQ 是一套用来出「哪个训练配置更好」类考题的基准流水线： 它会合成数据集、随机采样许多训练配置（candidate）、真正跑训练得到 ground-truth 指标，再据此出选择题。

本 side project 借用同一流水线，但问题改成：

给定很多「配置 → 真实测试分数」的例子之后，TabPFN 能不能猜从没见过的新配置大概能拿到多少分？ 猜得准不准，用误差和排序准确率来量。

也就是：把「调参 / 选架构」看成一张小表上的回归问题，看表格基础模型有没有用。

3. 整体实验流程

编排脚本：experiments/tabpfn_settings/scripts/run_family_pipeline.py。 下面四类任务（dataset family）各自独立跑完一整条流水线——不把不同任务的行混在一起训练。

造一份固定的数据集

调用 ArchitectureIQ 的 create-dataset：按配置生成一份合成数据，写到磁盘。 同一 family 下，后面所有「训练配置」都在同一份数据上比，避免「数据难不难」和「配置好不好」缠在一起。

随机采样许多训练配置

调用 generate-candidates：从池子里随机抽模型结构、优化器超参等，写成 candidate_spec.json，并自动生成可运行的 model.py / optimizer.py / loss.py / train.py。

本次每个 family 抽 40 套；变化轴是 模型 + 优化器；同一批共享同一个训练预算（看过多少样本）。

真正跑训练，得到「标准答案」分数

对每一套配置，执行它生成的 train.py（用 3 个随机种子），把测试集上的平均指标写进 results/summary.json。这就是表格的标签 y——不是手算，也不是用另一套逻辑估出来的。

若某次跑出无穷大/非法数值，建表时丢掉该行，所以有效行数可能略少于 40。

把配置压成表格行

用 encode_spec 把 JSON 配置摊平成数字/类别列（深度、宽度、学习率……），加上标签 y，存成 CSV。

用 TabPFN 和几个朴素方法做「猜分」比赛

把表划成 5 折：每折用一部分行给模型看，预测剩下的行，最后拼出所有行的预测再算指标。

4. 表格长什么样：输入 X、输出 y

请先分清两件完全不同的「训练」

  1. 层 A（造标签）：ArchitectureIQ 按某套配置，真的训练一个小网络，得到测试 MSE / 交叉熵。这很慢，但分数可信。
  2. 层 B（猜标签）：TabPFN / Ridge 等只看「配置特征 → 分数」这张小表，试图对新配置猜分数。这里的 fit 不会去改 TabPFN 的大预训练权重。

输入 X（一行 = 一套训练配置）

特征只来自配置文件，绝不放入最终测试分数、训练曲线等，否则就是泄题。

类别列名（示意）含义
模型身份model_type, trainable_parameter_count, log_params用的哪种网络、有多大
训练预算batch_size, training_steps, total_samples_seen一批多大、走多少步、总共看过多少样本
优化器optimizer_type, lr, weight_decay, momentum…本次会随机变
损失loss_id, loss_lambda本次基本固定
结构细节depth, width, residual, … 或 d_model, num_layers…随模型类型有的有、有的空缺

输出 y

  • 回归类任务：测试集均方误差 mean_test_mse（越小越好）
  • 分类 / 语言模型：测试集交叉熵 mean_test_ce（越小越好）
  • 模型要输出的是一个实数 ŷ =「我猜这套配置最终大概是这个分数」

5. 怎么公平地测「猜得准不准」

项目做法（人话）
怎么切分把所有配置行随机打乱，切成 5 份；轮流留 1 份当考题，其余给模型看
防作弊同一套配置不会既出现在「给模型看」又出现在「要它猜」里
对照方法① 闭着眼睛猜平均值；② Ridge 线性回归；③ HistGB 树模型；④ TabPFN
MAE / RMSE猜的分数和真分数差多少（越小越好）
Spearman排序相关：相对好坏顺序有没有猜对（越高越好；猜常数则无意义）
成对排序正确率任意两套配置，真值谁更好 vs 预测谁更好，一致的比例（越高越好）
