ArchitectureIQ · side/tabpfn-settings · generated candidates

按 dataset family 生成 settings → TabPFN

本次不再用 frozen pack 凑数。对每个 family：create-dataset → 随机采样 candidate（vary model+optimizer）→ 执行 generated train.py 得 GT → 5-fold 预测 selection metric。

输入 / 输出 / 训练测试（统一协议）

X = flatten(candidate_spec)：model / optimizer / loss / budget 字段（见 features.py）
y = results/summary.json 的 mean_test_mse 或 mean_test_ce（执行 GT，非手算）
TabPFN.fit(X_train,y_train)：不更新 foundation 权重；条件行数 = 该折 n_train
predict(X_test) → ŷ；指标 MAE/RMSE/Spearman/pairwise（OOF 拼接）
  • Profile：v2.5-tabpfn-settings（n_seeds=3）
  • 每 family 采样 count=40，axes=model,optimizer
  • 设备：A100 CUDA · TabPFN v2.5 regressor
