ArchitectureIQ · side/tabpfn-settings · Phase P0

用 TabPFN 从 candidate settings 预测 test CE

把 ArchitectureIQ 的模型 / 优化器 / 损失 / budget 编成表格行，用已有 XOR pack 的 ground-truth mean_test_ce 做 5-fold CV，比较均值基线、Ridge、HistGradientBoosting 与 TabPFNRegressor。

一句话结论

在 N=63、单数据集、优化器/损失/budget 几乎固定、主要靠架构轴变化的 P0 可行性实验上， TabPFN v2.5 全面优于经典基线：Spearman 0.721（Ridge 0.567）， 成对排序准确率 0.772（Ridge 0.692）。P0 样本量偏小，结果只作可行性信号，不代表 P1 随机采样规模下的最终结论。

实验设定（固定轴）

轴取值说明
Dataset family synthetic_tabular_classification XOR 风格合成表格分类
Dataset instance stabcls_953608 全表同一实例，避免数据难度混杂
Profile v2.5-xor-holdout XOR holdout pack 来源 profile
Selection metric / label test_ce → mean_test_ce 来自执行 train.py 得到的 GT summary，非手算
Budget batch=32 · steps=256 · samples_seen=8192 全表唯一；无 budget 轴变化
Optimizer Adam · lr=1e-3 · wd=0 全表唯一；无 optimizer 轴变化
Loss cross_entropy 全表唯一；无 loss 轴变化
Data source XOR question pack 中已有 GT 的 candidates 非随机重采样（那是 P1）
设定含义：P0 实际是在「同数据、同训练日程、同 Adam/CE」下，预测不同 MLP/KAN 架构的 test CE。 特征表里仍保留 optimizer/loss/budget 列（常数列），以便与后续 P1 随机 settings 管线对齐。

变化的架构空间

以下为表中实际出现的取值（来自 frozen pack，非均匀网格）。

MLP（n=39）

  • depth ∈ {1,2,3,4,5,6}
  • width ∈ {16,32,64,128}
  • residual ∈ {true, false}
  • activation_primary ∈ {relu, silu, gelu, leaky_relu}
  • layer_norm_frac ∈ {0, 1/6, 0.25, 1/3, 0.4, 0.5, 2/3, 1}
  • 参数量约 354 – 100738

KAN（n=24）

  • depth ∈ {1,2} · width ∈ {8,16}
  • grid_size ∈ {3,5,7} · spline_order=3
  • base_activation ∈ {silu, tanh}
  • 参数量约 672 – 6336
  • MLP 专属列（residual / act / LN）对 KAN 行为 NaN

特征编码

每行 = 一个 candidate_spec.json + results/summary.json。用于模型的 19 列（全空列已剔除）：

model_type, trainable_parameter_count, log_params, batch_size, training_steps, total_samples_seen, optimizer_type, lr, log_lr, weight_decay, loss_id, depth, width, residual, layer_norm_frac, activation_primary, grid_size, spline_order, base_activation

  • 缺失架构字段保留为 NaN（跨 model_type 混表）
  • TabPFN 路径把 bool+NaN（如 residual）规范成字符串类别，避免 sklearn/pandas.NA 冲突
  • sklearn 基线：数值列 median impute + 标准化；类别列 most-frequent + one-hot

评估协议

  • Split：按行（candidate）5-fold CV，KFold(shuffle=True, random_state=0)；无同一 candidate 泄漏
  • 指标：MAE、RMSE、Spearman ρ、pairwise ranking accuracy（对所有不等对，预测序是否与真值序一致；CE 越低越好）
  • 模型： train_mean（全局均值）、Ridge(α=1)、HistGradientBoosting(max_depth=4, max_iter=200)、 TabPFNRegressor.create_default_for_version(V2_5)
  • 硬件 / 软件：远程 A100 80GB；torch cu124；TabPFN 权重经 hf-mirror.com 拉取 Prior-Labs/tabpfn_2_5 的 tabpfn-v2.5-regressor-v2.5_default.ckpt； TABPFN_SKIP_LICENSE=1 跳过外网 license ping
