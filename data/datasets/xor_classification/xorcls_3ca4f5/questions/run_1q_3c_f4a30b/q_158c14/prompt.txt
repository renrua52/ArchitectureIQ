## Dataset
XOR binary classification on tabular features. Features are drawn i.i.d. from a standard normal; the label depends on the *sign agreement* of two active coordinates, so no linear function of the inputs separates the classes at all — a model must compose the two coordinates multiplicatively. Any remaining coordinates are pure distractors. The dataset card below states the active coordinates and the exact label rule. Every candidate trains on the same materialized train/test splits.

### Data-generating and classification rule
- Rule family: `xor`; active coordinates: `x_1`, `x_3`
- Feature distribution: every coordinate is sampled independently from `Normal(0, 1)`.
- Latent score:
  - `s(x) = -x_1·x_3`
- Label rule: `y = 1` exactly when `s(x) > 0`; otherwise `y = 0`.
- XOR interpretation: `x` is class 1 exactly when its two active coordinates have opposite signs, and class 0 when they share a sign.
- Bayes decision boundary: `s(x) = 0`; labels are an exact function of `x`, so this boundary is attainable.
- Threshold calibration: `0` was chosen from 4096 independent calibration rows as the closest round value to the 50% quantile of `s(x)`; on those 4096 rows it labels 48.7% of them class 1.
- Reproducibility: point seed `5220`, calibration seed `6220`.

### Data splits and training protocol
- Task: binary classification on one fixed synthetic tabular train/test split.
- Input shape: float32 `[N, 4]`; labels: int64 `[N]` in `{0, 1}`.
- Train rows: 1024; held-out test rows: 2048.
- Every choice receives the same materialized split; minibatches sample train indices uniformly with replacement.
- Evaluation: **test cross-entropy** is primary; test accuracy is auxiliary only.
- Reference device: cpu

```python
class MLPBlock(nn.Module):
    """One hidden layer: gelu(Linear(norm(x)))."""

    def __init__(self, width: int, use_layer_norm: bool) -> None:
        super().__init__()
        self.norm = nn.LayerNorm(width) if use_layer_norm else nn.Identity()
        self.linear = nn.Linear(width, width)
        self.act = nn.GELU()

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        h = self.linear(self.norm(x))
        return self.act(h)


class Model(nn.Module):
    def __init__(self) -> None:
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(4, 64),
            nn.GELU(),
            MLPBlock(width=64, use_layer_norm=True),
            MLPBlock(width=64, use_layer_norm=False),
            MLPBlock(width=64, use_layer_norm=False),
            MLPBlock(width=64, use_layer_norm=False),
            MLPBlock(width=64, use_layer_norm=True),
            nn.Linear(64, 2),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.net(x)
```
