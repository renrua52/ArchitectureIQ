## Dataset
Two-spirals binary classification. The input is 2-dimensional by construction. Points are drawn along one of two interleaved Archimedean arms that differ by a half-turn phase; the label *is* the arm a point came from, so the classes are exactly balanced and there is no threshold to calibrate. The decision boundary spirals outward, so its complexity grows with the number of turns — stated in the dataset card below. Every candidate trains on the same materialized train/test splits.

### Data-generating and classification rule
- Rule family: `spiral`; active coordinates: `x_0`, `x_1` (input is 2-dimensional).
- Point distribution: classic interleaved two-spirals. Each point is drawn along one of two Archimedean arms: with `t` uniform on `[0.5, 0.5 + 5π]` (2.5 full turns), radius `r = t`, coordinates `(r·cos(t + phase), r·sin(t + phase))` with `phase ∈ {0, π}`.
- Label rule: `y = 0` for points drawn from the `phase = 0` arm and `y = 1` for points from the `phase = π` arm; both arms are equally likely, so classes are balanced.
- Nominal soft score (intuition only): `s(x) = sin(atan2(x_1, x_0) − ‖x‖₂)`; its zero level sets trace the two arms, but labels come from the generative arm, not from thresholding `s(x)`.
- Bayes decision boundary: assign each point to the nearer of the two arms (up to label-flip symmetry); with 2.5 full turns the arms interleave, so the boundary is highly non-linear.
- Reproducibility: point seed `5231`, spiral turns `2.5`.

class MLPBlock(nn.Module):
    """One hidden layer: gelu(x + Linear(norm(x)))."""

    def __init__(self, width: int, use_layer_norm: bool) -> None:
        super().__init__()
        self.norm = nn.LayerNorm(width) if use_layer_norm else nn.Identity()
        self.linear = nn.Linear(width, width)
        self.act = nn.GELU()

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        h = self.linear(self.norm(x))
        h = h + x
        return self.act(h)


class Model(nn.Module):
    def __init__(self) -> None:
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 64),
            nn.GELU(),
            MLPBlock(width=64, use_layer_norm=True),
            MLPBlock(width=64, use_layer_norm=True),
            MLPBlock(width=64, use_layer_norm=False),
            MLPBlock(width=64, use_layer_norm=False),
            nn.Linear(64, 2),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.net(x)
