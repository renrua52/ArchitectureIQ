## Dataset
Synthetic tabular binary classification. Features are drawn i.i.d. from a standard normal; a latent score `s(x)` over a few active coordinates is thresholded at a fixed cut-off chosen near the median of `s(x)`, so the two classes are close to balanced. The score is non-linear in the features, so no linear function of the inputs reproduces the boundary. The dataset card below states the exact rule family, active coordinates, weights, threshold, and the class balance it produces. Every candidate trains on the same materialized train/test splits.

### Data-generating and classification rule
- Rule family: `sparse_interaction`; active coordinates: `x_0`, `x_5`
- Feature distribution: every coordinate is sampled independently from `Normal(0, 1)`.
- Latent score:
  - `s(x) = -0.875·x_0·x_5`
- Label rule: `y = 1` exactly when `s(x) > 0`; otherwise `y = 0`.
- Bayes decision boundary: `s(x) = 0`; labels are an exact function of `x`, so this boundary is attainable.
- Threshold calibration: `0` was chosen from 4096 independent calibration rows as the closest round value to the 50% quantile of `s(x)`; on those 4096 rows it labels 51.2% of them class 1.
- Reproducibility: point seed `5243`, calibration seed `6243`.

```python
class MLPBlock(nn.Module):
    """One hidden layer: silu(x + Linear(norm(x)))."""

    def __init__(self, width: int, use_layer_norm: bool) -> None:
        super().__init__()
        self.norm = nn.LayerNorm(width) if use_layer_norm else nn.Identity()
        self.linear = nn.Linear(width, width)
        self.act = nn.SiLU()

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        h = self.linear(self.norm(x))
        h = h + x
        return self.act(h)


class Model(nn.Module):
    def __init__(self) -> None:
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(16, 256),
            nn.SiLU(),
            MLPBlock(width=256, use_layer_norm=True),
            MLPBlock(width=256, use_layer_norm=False),
            MLPBlock(width=256, use_layer_norm=True),
            MLPBlock(width=256, use_layer_norm=False),
            nn.Linear(256, 2),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.net(x)
```
