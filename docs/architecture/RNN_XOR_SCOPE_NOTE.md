# RNN / XOR 扩展：当前取舍

目标是在有限时间内扩展 benchmark 的**架构覆盖面**，而不是一次覆盖所有常见架构与任务。

## 本轮保留

- 在既有序列任务上新增 **GRU**，作为递归模型，与 Transformer 形成同任务的架构对照。
- 在既有 `synthetic_tabular_classification` 中加入连续、轻度带噪的 **XOR** 决策边界，用于诊断 MLP / KAN 的非线性交互建模。

GRU 属于 RNN；本轮只引入 GRU，不同时加入 vanilla RNN，避免把题目变成参数量或训练稳定性的比较。现有 `bigram_lm` 只适合衡量有限预算下的序列模型选择，**不应**宣称它测量长程记忆。

## 本轮不做

- CNN：二维坐标任务不天然具有卷积的空间归纳偏置；CNN 应留给单独的程序化视觉/空间任务。
- 双螺旋：先不作为正式 benchmark family；其结果对噪声、样本密度和训练预算更敏感，适合后续探索性 stress test。
- 同时把 RNN/GRU、CNN、XOR、双螺旋全部纳入：这会超出本轮可校准、可审计的范围。

## 质量边界

新内容进入新的 profile，不改动冻结的旧 profile。候选需控制容量与训练预算，并检查是否出现“看到模型类型就能猜答案”的捷径；目标是稳定、可解释的 ground truth，而非单纯跑通新模型。
