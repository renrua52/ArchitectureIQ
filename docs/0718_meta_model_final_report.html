1. Setting 定义

1.1 Baseline = 每个 dataset 训练一个模型

最简单的 setting：不跨 dataset 共享样本，不涉及跨 dataset 泛化。

项值
协议dataset_pooled_id
模型数15（每个 dataset 一个）
每模型 train rows600（部分 300）
每模型 locked validation66–67
特征维度35–91（因 family 而异）
目标预测 log(mean_loss)（mean 跨 5 seed）
评测每 environment 穷举 C(n,3) 三元组
显著性筛选gap≥0.05 且 win_rate≥0.7 且 non_overlap

1.2 共享模型 = 1 个模型跨所有 dataset

全部 9,000 train rows 训练一个模型，特征里显式编码 dataset identity（122 维）。不涉及跨 family 泛化，只是让模型看到所有 dataset 的样本。

1.3 直接预测 winner = pairwise 分类

不做回归，直接预测"候选 A 是否优于候选 B"。输入是两个候选特征的差值，输出是二分类。三元组评测时做 3 次 pairwise 比较，投票选出 winner。

3. 关键结论

最优 meta-model：共享回归 ExtraTrees = 82.11%
Setting：1 个模型，9,000 train rows，122 维特征（full + dataset identity），300 棵 depth-16 树，预测 log(mean_loss)。比 baseline 78.33% 高 3.78pp，比旧报告的 63.50% 高 18.61pp。
为什么之前只有 63.50%？两个原因：
  1. Metric 错误：旧 metric 用全部 C(n,3) 三元组（含 42% 不显著的噪声题），低估了约 9pp。
  2. Setting 不够好：15 个独立模型各只 600 行，共享后 ExtraTrees 提升约 4pp。
直接预测 winner 的思路是对的方向，但当前实现还不够好。
  • GradientBoosting 分类器 74.85% — 不如回归 ExtraTrees 82.11%。
  • MLP 分类器（72.31%）明显优于 MLP 回归器（60.31%）—— 直接预测 winner 对 MLP 更合适。
  • 但 Global tree classifiers 反而很弱（56–62%）—— pairwise 差值特征可能破坏了树的原生特征判别能力。
  • Per-dataset ExtraTrees Clf 单 dataset 测试 83.18%，但全量结果待完成。

线性回归不弱吗？

不。OLS 和 Ridge 在显著性筛选后只有 45–61%，远低于树模型的 75–82%。这证实了 setting→loss 的映射是高度非线性的，线性模型无法捕捉。之前说的"linear regression 80%+"是 Phase-A 3 环境窄协议下的数字，不能泛化。

4. 显著性检验规范

所有结果都经过 repo 的完整显著性检验（src/architecture_iq/significance/validator.py）：

条件默认值语义
gap_min0.05best 与 second 候选的 mean_{metric} 绝对差
win_rate_min0.75 seed 里 winner 一致率（至少 4/5）
use_non_overlapTruewinner+std < runner_up−std（1 个 std，非 2 sigma）

152,592 个三元组中只有 87,837 个（57.6%）通过全部三个条件。其余 42.4% 是 GT 跨 seed 分不开的噪声题，不应计入 accuracy。

5. 多 seed 标准差

每个候选的 GT 来自 5 个 seed 的真实训练。summary.json 记录 mean_{metric}、std_{metric}、seed_results[].final_{metric}。显著性检验用的就是这些跨 seed 统计。元模型本身只拟合一次，输入是静态配置特征，目标是 5 seed 平均的 log(mean_loss)。
